# Фронт для GitHub Pages

1. Залейте **содержимое** этой папки `frontend/` в репозиторий GitHub Pages
   (в корень pages или в `docs/` — как настроите).
2. В `js/config.js` пока можно оставить `apiBase: ""` — адрес API пропишем,
   когда будет публичный HTTPS к бэкенду.
3. Пришлите готовый URL вида `https://username.github.io/repo/` — подключим к боту.

Локально по-прежнему: `http://127.0.0.1:8000/app/`
